# SINAG design system

SINAG uses a solar-observatory language: near-black field surfaces, warm gold signals, restrained hairlines, and monospaced telemetry labels around editorial serif headlines.

## Tokens

- Background: `#090A0C`
- Surface: `#111216`
- Gold: `#D6A443`
- Solar: `#FFBF47`
- Highlight: `#FFE6A0`
- Text: `#F4F0E8`
- Muted: `#96918A`

## Rules

- Use orbit lines and measurement labels to connect visual motion to engineering work.
- Keep glow localized to the solar core; cards use borders and contrast instead of glass effects.
- Every animated idea has a readable static state and a reduced-motion path.
- Project cards state the actual contribution and link to verified public destinations.
