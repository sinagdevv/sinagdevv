# SINAG interactive site

This is the standalone Next.js experience behind the SINAG profile. It uses React Three Fiber, Drei, Three.js, and a small custom shader for the solar core.

Run locally from this directory:

```bash
npm install
npm run dev
```

Deploy with Vercel using `site/` as the root directory. See [`../docs/DEPLOYMENT.md`](../docs/DEPLOYMENT.md).
